# B1.1 Auxiliary-Calibration Robustness

This directory contains a bounded robustness and leakage-hardening experiment
for B1. It uses deterministic synthetic data and Python 3 standard library
only.

The experiment tests whether the B1 auxiliary-calibration signal survives
multiple seeds, sparse connected anchors, affine observer coloring, stronger
no-auxiliary baselines, and negative controls.

This is not an LLM experiment, not a substrate claim, not a grounding claim,
and not evidence of real-world transfer.
