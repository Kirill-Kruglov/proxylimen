# B2 Relational Order-Dimension Recovery Gate

This directory contains a bounded synthetic relational-structure recovery
experiment. It tests whether auxiliary calibration can recover a generated 2D
product-order relation from observer-colored coordinate observations.

The implementation uses Python 3 standard library only. It does not use
internet data, natural language corpora, LLM calls, external ML libraries, or
model training.

This result is not a substrate claim, not a grounding claim, not a semantic
boundary generator claim, and not evidence of real-world transfer.
