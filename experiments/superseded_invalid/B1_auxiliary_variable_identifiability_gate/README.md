# B1 Auxiliary-Variable Identifiability Gate

This directory contains a bounded synthetic identifiability experiment.

The experiment tests whether a latent scalar mixed with observer bias can be
recovered only when an explicit auxiliary observer variable and calibration
anchor overlaps are available. It uses deterministic synthetic data, Python 3
standard library only, and no external corpus, network access, LLM calls, or
model training.

This is not a substrate claim, not a grounding claim, and not evidence that the
toy result transfers to real-world language or internet-scale data.
